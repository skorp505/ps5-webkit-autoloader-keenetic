# Пейлоады сюда не кладутся

Здесь лежат **ваши** бинарники — репозиторий их не содержит и не должен:
это чужие проекты со своими лицензиями.

Установщик подхватывает всё, что найдёт в этой папке, пишет список в `payloads.json`
и подключает `src/relapse-payloads.js` в `src/main.js`. После того как на приставке
поднимется `elfldr` на порту 9021, она сама отправит эти файлы по порядку.
Компьютер после установки не нужен.

Сам Relapse этого больше не делает: в актуальной версии из `kexp.js` убрали
`loadOptionalPayloads()`, поэтому модуль отправки держим здесь. Отправка идёт
с приставки в `127.0.0.1:9021` — снаружи пейлоад отправить нельзя, браузеру
доступен только примитив эксплоита.

## Что положить

| Файл | Зачем | Порядок |
| --- | --- | --- |
| `pldmgr.elf` | Payload Manager | 1 |
| `allinOne.elf` | всё-в-одном от Akela-1979 | 2 |
| `kstuff.elf` | ядерный эксплоит kstuff (sleirsgoevy, Echo Stretch) | 3 |
| `etaHEN-*.bin` | сам HEN (LightningMods) | 4 |

Обязательны только `pldmgr.elf` и `allinOne.elf` — без них эксплоит работает,
но дополнительных полезностей не будет. `etaHEN` нужен, если хочешь нормальный
homebrew, а не голый доступ к ядру.

## Как положить

```bash
# на своей машине
cp ~/Загрузки/etaHEN-2.5B.bin ~/Загрузки/allinOne.elf payloads/

# проверить, что установщик их увидит
./install.sh --host 192.168.90.1 --password ... --source ...
```

Файлы `*.bin`, `*.elf` и всё прочее добавлены в `.gitignore`, случайно
закоммитить их не получится.

## Если пейлоад лежит уже на роутере

Установщик всё равно может отправить его вручную, компьютер для этого не нужен:

```bash
ssh -p 222 root@192.168.90.1 \
  /storage/www/relapse/send-payload.sh /storage/www/relapse/payloads/etaHEN-2.5B.bin
```

Вернуть исходный `src/main.js` без автоотправки:

```bash
./install.sh --host 192.168.90.1 --password ... --reset-payload-patch
```

Проверить, что всё на месте:

```bash
ssh -p 222 root@192.168.90.1 "cat /storage/www/relapse/payloads.json"
ssh -p 222 root@192.168.90.1 "grep -c relapse-payloads /storage/www/relapse/src/main.js"  # должно быть 1
```
